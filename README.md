# TaskFlow

A simple and responsive task management dashboard built with React.js and Tailwind CSS.

TaskFlow allows users to manage their daily tasks, filter tasks, search for tasks, mark tasks as completed, and add or delete tasks through a clean dashboard interface.

🔗 **Live Demo:** https://taskflow-s73.netlify.app/

## Features

- Dashboard with task statistics
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Search tasks by title
- Filter tasks by category
- Task priority levels
- Responsive design
- Mobile sidebar navigation
- Dark-themed user interface

## Tech Stack

- React.js
- Vite
- JavaScript
- Tailwind CSS
